## Anleitungen für Squarespace

### Meta-Description und SEO-Titel eintragen

Die Meta-Description ist der kurze Beschreibungstext, der bei Google unter dem blauen Link steht.

1. Links im Menü **Seiten** öffnen.
2. Mit der Maus über die gewünschte Seite fahren → **Zahnrad** ⚙ anklicken.
3. Reiter **SEO** wählen.
4. Text aus dem Report kopieren und bei **SEO-Beschreibung** einfügen. Den **SEO-Titel** im selben Fenster eintragen.
5. **Speichern**.

Die Texte sind auf die richtige Länge zugeschnitten (ca. 140–155 Zeichen). Bitte **1:1 übernehmen** — längere Texte schneidet Google ab.

### Hauptüberschrift (H1) setzen

Jede Seite braucht genau **eine** Hauptüberschrift, die sagt, worum es auf der Seite geht (z. B. «Baphumelele – Kinderheim in Khayelitsha»).

1. Seite öffnen → **Bearbeiten**.
2. Den obersten Titel-Text markieren.
3. In der Format-Leiste **Überschrift 1** wählen.
4. Kontrollieren, dass sonst nichts auf der Seite als «Überschrift 1» formatiert ist — weitere Titel sind **Überschrift 2** oder **3**.
5. **Speichern**.

### Texte ergänzen oder korrigieren

Seite öffnen → **Bearbeiten** → Textblock anklicken → ändern → **Speichern**. Was genau wo stehen soll, steht in der jeweiligen Aufgabe im Audit.

## Bitte beachten

- **Schreibweise wie auf der Website:** Du-Form und Schweizer Schreibweise (**ss** statt ß).
- **Nur Fakten verwenden, die stimmen.** Zahlen und Aussagen in den vorbereiteten Texten stammen von unserer Website. Wenn etwas veraltet ist: Haui melden statt stillschweigend ändern.
- **Finger weg von diesen Dingen** (das macht Haui, weil sonst Links oder die Übersetzung kaputtgehen können):
  - Seiten-Adressen («URL-Slug», z. B. `/ueberuns`) ändern
  - Seiten löschen oder im Menü verschieben
  - Alles unter **Code-Injection**, **Weglot** (Übersetzung) und **Domains**
- **Unsicher?** Lieber vorher fragen. Squarespace hat kein einfaches «Rückgängig» für gespeicherte Änderungen.

## Kleines Glossar

| Begriff | Bedeutung |
|---|---|
| **SEO** | Suchmaschinen-Optimierung: dafür sorgen, dass man uns bei Google findet |
| **Meta-Description** | Beschreibungstext unter dem Link in den Google-Ergebnissen; auch die Vorschau beim Teilen auf WhatsApp/Facebook |
| **SEO-Titel** | Der blaue, anklickbare Titel in den Google-Ergebnissen |
| **H1** | Die Hauptüberschrift einer Seite (in Squarespace: «Überschrift 1») |
| **URL-Slug** | Der hintere Teil der Seiten-Adresse, z. B. `/spenden` |
| **Impressionen** | Wie oft unsere Seite in Google-Ergebnissen angezeigt wurde |
| **Klicks / CTR** | Wie oft geklickt wurde / Anteil der Klicks an den Impressionen |
| **Position** | Durchschnittlicher Platz in den Google-Ergebnissen (1–10 = erste Seite) |
| **GSC** | Google Search Console — liefert die Zahlen zu Impressionen, Klicks, Position |
| **Audit** | Gesamtprüfung der Website mit Befunden und Massnahmen |
